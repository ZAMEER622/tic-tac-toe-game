## 🚀 Features

✅ **Two-Player Gameplay** - Play as X and O with a friend  
✅ **Win Detection** - Automatically detects rows, columns, and diagonals  
✅ **Draw Detection** - Recognizes when the game ends in a tie  
✅ **Turn Indicator** - Shows whose turn it is  
✅ **Reset Button** - Start a new game anytime  
✅ **Responsive Design** - Works on mobile, tablet, and desktop  
✅ **Modern UI** - Clean gradient background with smooth hover effects  
✅ **Docker Support** - Containerized for easy deployment

## 🎮 How to Play

1. **Game starts** with Player **X**
2. **Click** on any empty cell to place your mark
3. Players **take turns** (X → O → X → O)
4. **Win** by getting 3 in a row (horizontally, vertically, or diagonally)
5. If all 9 cells fill with **no winner**, it's a **draw**
6. Click **Reset Game** to play again
